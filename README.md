# Catálogo RFID y NFC

Catálogo estático basado en los productos publicados por [MIND RFID](https://www.mindrfid.com/products/). Los nombres se conservan en el idioma original y cada producto abre la ficha del fabricante. Las imágenes se cargan desde el CDN del proveedor.

## GitHub Pages

1. Crea un repositorio para el catálogo.
2. Sube los archivos de esta carpeta a la raíz de la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, luego **main** y **/(root)**. Guarda.
4. Abre la URL que muestra GitHub Pages cuando finalice el despliegue.

Para previsualizar el catálogo en tu equipo, abre `index.html` en el navegador. Puedes editar el listado en `products.js`.
